# Assets

This folder contains the original user-supplied Expo Freight logo, supplied concept artwork and its gallery crops, an AI-generated illustrative freight hero, self-hosted typefaces and their licence notices. The logo must remain visually unchanged. Gallery crops are presentation details of the supplied concept, never evidence of current operations. ASSETS.md records provenance. Every runtime image and font is served locally. Optimise formats without changing the branding, retain original references and verify every consuming relative path with npm test.
